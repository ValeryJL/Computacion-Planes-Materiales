# I145 - Diseño De Experiencia de Usuario

- **Tipo**: Optativa Tipo A (Facultad de Informática)
- **Código Plan 2011**: I145
- **Código Plan 2024**: I1145
- **Profesor/a a cargo**: I. Harari
- **Semestre de cursada**: Primer semestre
- **Carga horaria**: 6 horas semanales (96 horas totales)
- **Correlativas Plan 2011**: Ingeniería de Software (I110)
- **Correlativas Plan 2024**: Ingeniería de Software (I1110)

## Descripción de la Asignatura
Principios de interacción persona-computadora, prototipado interactivo, evaluación heurística de usabilidad, accesibilidad y diseño centrado en el usuario.
