# I150 - Introducción a la Computación Móvil

- **Tipo**: Optativa Tipo A (Facultad de Informática)
- **Código Plan 2011**: I150
- **Código Plan 2024**: I1150
- **Profesor/a a cargo**: Challiol
- **Semestre de cursada**: Segundo semestre
- **Carga horaria**: 6 horas semanales (96 horas totales)
- **Correlativas Plan 2011**: Ingeniería de Software (I110), Redes de Datos II (I114)
- **Correlativas Plan 2024**: Ingeniería de Software (I1110), Redes de Datos II (I1114)

## Descripción de la Asignatura
Desarrollo de aplicaciones nativas e híbridas para Android e iOS, ciclo de vida en dispositivos móviles, almacenamiento local y geolocalización.
