# I122 - Computabilidad y Complejidad

- **Tipo**: Optativa Tipo A (Facultad de Informática)
- **Código Plan 2011**: I122
- **Código Plan 2024**: I1122
- **Profesor/a a cargo**: Tinetti
- **Semestre de cursada**: Segundo semestre
- **Carga horaria**: 6 horas semanales (96 horas totales)
- **Correlativas Plan 2011**: Matemática D1 (F0310), Programación III (I103)
- **Correlativas Plan 2024**: Matemática D (F1306), Programación III (I1103)

## Descripción de la Asignatura
Máquinas de Turing, funciones recursivas, tesis de Church-Turing, reducibilidad, jerarquía de clases P, NP y NP-completitud.
