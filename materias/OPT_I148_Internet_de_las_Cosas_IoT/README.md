# I148 - Internet de las Cosas

- **Tipo**: Optativa Tipo A (Facultad de Informática)
- **Código Plan 2011**: I148
- **Código Plan 2024**: I1148
- **Profesor/a a cargo**: J. Díaz, Vilches, Pagano
- **Semestre de cursada**: Primer semestre
- **Carga horaria**: 6 horas semanales (96 horas totales)
- **Correlativas Plan 2011**: Taller de Lenguajes II (I107), Redes de Datos II (I114)
- **Correlativas Plan 2024**: Taller de Lenguajes II (I1107), Redes de Datos II (I1114)

## Descripción de la Asignatura
Protocolos MQTT, CoAP, dispositivos embebidos, sensores y actuadores, plataformas en la nube para telemetría y procesamiento de datos en el borde (Edge Computing).
