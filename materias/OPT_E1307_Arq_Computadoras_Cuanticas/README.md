# E1307 - Introducción a la Arquitectura de Computadoras Cuánticas

- **Tipo**: Optativa Tipo B (Facultad de Ingeniería)
- **Código Plan 2011**: E1307
- **Código Plan 2024**: E1307
- **Profesor/a a cargo**: Área Computación Cuántica
- **Semestre de cursada**: Primer semestre
- **Carga horaria**: 6 horas semanales (96 horas totales)
- **Correlativas Plan 2011**: (E0306) Taller de Proyecto I
- **Correlativas Plan 2024**: (E1306) Taller de Proyecto I

## Descripción de la Asignatura
Arquitectura de procesadores cuánticos físicos (superconductores, trampas de iones), mitigación de errores cuánticos, compiladores cuánticos y capas de control criogénico.
