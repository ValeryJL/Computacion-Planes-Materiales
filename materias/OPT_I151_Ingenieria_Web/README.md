# I151 - Ingeniería de Aplicaciones Web

- **Tipo**: Optativa Tipo A (Facultad de Informática)
- **Código Plan 2011**: I151
- **Código Plan 2024**: I1151
- **Profesor/a a cargo**: Urbieta
- **Semestre de cursada**: Segundo semestre
- **Carga horaria**: 6 horas semanales (96 horas totales)
- **Correlativas Plan 2011**: Taller de Lenguajes II (I107), Ingeniería de Software (I110)
- **Correlativas Plan 2024**: Taller de Lenguajes II (I1107), Ingeniería de Software (I1110)

## Descripción de la Asignatura
Diseño arquitectónico web para escalabilidad, patrones JAMstack, micro-frontends, optimización de rendimiento CWV y despliegue CI/CD.
