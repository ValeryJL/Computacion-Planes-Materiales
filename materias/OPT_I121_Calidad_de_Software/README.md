- **Tipo**: Optativa Tipo A (Facultad de Informática)

- **Código Plan 2024**: I1121
- **Profesor/a a cargo**: Pasini, Pesado

## Descripción de la Asignatura
Estándares de calidad ISO/IEC 25010, modelos de madurez CMMI, métricas de complejidad ciclomática, integración continua y aseguramiento de calidad (QA).
