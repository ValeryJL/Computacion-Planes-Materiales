# I167 - Introducción a la Programación Cuántica

- **Tipo**: Optativa Tipo A (Facultad de Informática)
- **Código Plan 2011**: I167
- **Código Plan 2024**: I1167
- **Profesor/a a cargo**: Corbalán
- **Semestre de cursada**: Segundo semestre
- **Carga horaria**: 6 horas semanales (96 horas totales)
- **Correlativas Plan 2011**: Conceptos de Arquitectura (I105), Bases de Datos (I108)
- **Correlativas Plan 2024**: Arquitectura (I1105), Ingeniería de Software (I1110)

## Descripción de la Asignatura
Qubits, compuertas cuánticas, algoritmos de Deutsch-Jozsa, Grover y Shor, simuladores cuánticos Qiskit y computación cuántica híbrida.
